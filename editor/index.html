Lights: paint where light comes from. By day nothing changes; at dusk and night the game glows these pixels and casts a pool of light around each patch (pick time above the canvas to see it). Smoke rises from its patches day and night. Shows at changes when this layer shows.

Save to GitHub

The editor commits your art straight to the repository, so it is versioned and the site redeploys with it. It needs a fine-grained personal access token (GitHub → Settings → Developer settings → Fine-grained tokens): repository access only this repository, permission Contents: Read and write. The token is kept in this browser only (localStorage) and sent only to api.github.com.
